# React Roadmap

## Why,When, How

- Why to learn react?
  - hype, jobs and trend, fast UI development that is
  - managed and build complex frontend

- When to learn react?
  - After mastering js
  - when you understand how front-end work and design
  - fast and rapid UI development

- How to learn react
  - follow the roadmap and start building projects, learn concept through building and docs rather that just following tutorials

## Why and how react started?

- Facebook had issue named "Phantom Message" where message notification count was not updated even if message was read or replied i.e. UI and State not getting synced creating inconstancy between them
- Dan ... from facebook came up with a library which update the state consistently.

## Framework vs Library

- Framework : strict rules, but gets more baked in features
- Library : freedom to implement in you way, need to configure and setup thing for extra feature
